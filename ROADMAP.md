# Roadmap

## Phase 1 -- Current

- Core configurable terminal grid (up to 6x5)
- CONTROL mode with AI-driven Stimulus / Will / Supply flow analysis
- Session cost tracking, broadcast, auto-restart, task queue
- Grid presets and session restore

## Phase 2 -- Structured Analysis Output

- Structured analysis response format (blocked / confidence / evidence fields)
- 9-cell experience optimization: active-only view, stalled cell detection
- Per-cell status indicators based on analysis results

## Phase 3 -- Automation and Workflow

- Notification-driven task queue automation
- Auto-trigger analysis on configurable intervals
- Expanded template presets for common workflows

## Phase 4 -- Extensibility

- Plugin system for custom analysis backends and cell behaviors
- Community preset sharing
- Third-party tool integrations
